I build software that turns operational problems into measurable improvements, focusing on ordering, inventory and receivables in wholesale distribution.

### Toptanik: B2B ordering platform for wholesalers

[toptanik.com.tr](https://toptanik.com.tr) · live, in pilot with the first wholesaler

- Multi-tenant B2B platform where dealers order from their wholesaler's catalog (web and iOS app; the app is in App Store review)
- Orders, stock, tiered discounts, receivables, cheques/promissory notes and returns in one system
- Integration with the BizimHesap accounting software (about 2,900 products and customer accounts imported)
- Tech: TypeScript, Next.js, PostgreSQL (Prisma), Expo / React Native, Python
- 450+ automated tests; AI-assisted development with Claude Code

### Industrial engineering: capstone project

Team project with Alperen Ayhan, using data from the platform:

- Demand classification (ABC–XYZ) and comparison of seven forecasting methods with rolling-origin backtesting
- Inventory policies: (s,Q), (R,S), (R,s,S) and stochastic dynamic programming; budget-constrained multi-item optimization
- Discrete-event simulation with SimPy to compare policies statistically
- Queueing analysis (Erlang B/C) of order handling to measure process efficiency
